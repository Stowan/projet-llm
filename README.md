# Projet LLM + n8n

Ce projet utilise un **Large Language Model (LLM)** en local, automatisé via **n8n**.

---

## Technologies utilisées

- **n8n** : pour orchestrer des automatisations, API et intégrations.
- **Python / Node.js** : scripts pour interagir avec le LLM localement.
- **LLM local** : modèle exécuté sans dépendance à des APIs externes (par ex. LLaMA, Mistral, GPT4All…).
- **Git + GitHub** : pour la collaboration.
